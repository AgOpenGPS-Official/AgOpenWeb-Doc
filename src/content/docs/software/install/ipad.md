There are two ways to use an iPad.

## As the screen for another computer

If AgOpenWeb runs on a computer in the cab, an iPad needs no install at all.
Open Safari and go to that computer's address: see
[Using a second screen](/software/install/second-screen/).

## As the whole system

AgOpenWeb also runs on the iPad itself: the host and the screen together in one
app. While AgOpenWeb is in beta, the app is distributed through Apple's
**TestFlight**.

1. Install **TestFlight** from the App Store.
2. Open your AgOpenWeb TestFlight invitation on the iPad and accept it.
3. Install AgOpenWeb from TestFlight and open it. The guidance screen fills
   the display.

:::caution[Keep it in front]
iPadOS does not let an app keep working in the background. AgOpenWeb only
guides while it is the app on screen. Switch to another app and guidance stops.

**Guided Access** (Settings, then Accessibility) pins the iPad to one app and
prevents a stray swipe from leaving it.
:::

## The modules still need a cable

An iPad reaches the modules through a USB-C or Lightning Ethernet adapter, not
over Wi-Fi: see
[What you need](/software/what-you-need/#an-ethernet-cable-to-the-modules).
